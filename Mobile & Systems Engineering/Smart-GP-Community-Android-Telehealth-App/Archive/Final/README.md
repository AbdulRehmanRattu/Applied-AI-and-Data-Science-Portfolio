# Smart General Practitioner Community (SGPC) Android Application

## Overview

The Smart General Practitioner Community (SGPC) application provides an intuitive mobile healthcare platform connecting patients with licensed general practitioners and clinical specialists.

## Key Features

- Secure patient authentication and profile management
- Doctor directory with specialty filtering (Cardiology, Dermatology, General Practice, Pediatrics)
- Interactive appointment scheduling and calendar booking
- Digital prescription and medical history record keeping
- Clean Model-View-ViewModel (MVVM) architecture with Kotlin Coroutines

## Build and Installation

Import the project in Android Studio (Hedgehog or newer) from `SGPC_App/` and build the project using Gradle.

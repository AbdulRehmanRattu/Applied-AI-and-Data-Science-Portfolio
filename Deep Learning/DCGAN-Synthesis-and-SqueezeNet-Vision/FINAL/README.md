# Deep Generative Adversarial Networks (DCGAN) and SqueezeNet Classifier

## Overview

This repository contains implementations of two core deep learning vision models:
1. **DCGAN (Deep Convolutional Generative Adversarial Network)**: Generative synthesis of visual distributions from random latent vectors with latent space interpolation.
2. **SqueezeNet Classifier**: Edge-optimized convolutional image classifier using Fire Modules for lightweight parameter efficiency.

## Key Files

- `GANS_FINAL.ipynb`: Complete DCGAN architecture, generator/discriminator training loop, and latent space traversal.
- `Classifier.ipynb`: SqueezeNet architecture with Fire modules, training accuracy/loss curves, and prediction evaluation.
